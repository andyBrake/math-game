# Spec Delta

## MODIFIED Requirements

### Requirement: 教材覆盖范围
系统 SHALL 内置北师大版小学数学四年级上册（8 个单元）与四年级下册（6 个单元）的完整单元清单，并按教材顺序排列，共 66 个知识点。未实现的年级与学期 SHALL 标记为 `todo` 且不可进入。

#### Scenario: 展示北师大版单元清单
- **WHEN** 用户选择四年级上册
- **THEN** 系统按教材顺序列出 8 个单元（认识更大的数 / 线与角 / 整数乘法（二）/ 我们生活的空间（二）/ 运算律 / 图形的奥秘 / 运用数量关系解决问题 / 数据的表示和分析（一））
- **AND** 选择四年级下册时列出 6 个单元（小数的意义和加减法 / 认识三角形和四边形 / 小数乘法 / 观察物体 / 认识方程 / 数据的表示和分析）

#### Scenario: 其他年级显示为待开发
- **WHEN** 用户查看一年级至六年级的年级列表
- **THEN** 四年级以外的年级显示为"敬请期待"状态
- **AND** 该年级不可被选中进入

### Requirement: 单元元数据
每个单元 SHALL 包含唯一标识、显示名称、所属学期、教材顺序、知识点列表，以及是否需要图形渲染的标记。单元标识 SHALL 在全部学期内唯一。

#### Scenario: 图形单元被标记
- **WHEN** 系统加载教材数据
- **THEN** 涉及角度量、画角、观察物体、三角形、条形图/折线图等图形渲染的单元被标记为需要图形渲染
- **AND** 其余单元被标记为纯文字单元
