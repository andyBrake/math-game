# Spec Delta

## Purpose

定义金币商店的商品目录、购买与装备流程，以及头像、庆祝动作、攻击特效、胜利音乐四类商品在游戏中的实际表现。

## ADDED Requirements

### Requirement: 商店入口与商品目录

系统 SHALL 提供 `#/shop` 商店视图，按头像、胜利音乐、攻击特效、庆祝动作四类展示商品；每件商品 MUST 显示预览、名称、价格与当前状态（可购买 / 已拥有 / 使用中）。

#### Scenario: 打开商店

- **WHEN** 玩家点击顶栏金币区域
- **THEN** 进入商店视图并显示当前余额
- **AND** 四类商品全部可见

#### Scenario: 商品状态

- **WHEN** 玩家尚未购买某件商品
- **THEN** 该商品显示价格与"购买"按钮
- **WHEN** 玩家已购买但未装备
- **THEN** 显示"使用"按钮
- **WHEN** 玩家已装备
- **THEN** 显示"使用中"且不可重复购买

### Requirement: 购买与装备

购买 MUST 扣除对应金币并把商品标记为已拥有；余额不足时 MUST 拒绝购买并提示还差多少金币；已拥有的商品 MUST NOT 重复扣费。购买成功后 SHALL 自动装备该商品。装备状态 MUST 持久化。

#### Scenario: 余额不足

- **WHEN** 玩家余额 5 枚，尝试购买 18 枚的头像 A
- **THEN** 不扣金币、不改变已购状态
- **AND** 提示"还差 13 枚金币"

#### Scenario: 购买成功

- **WHEN** 玩家余额足够并点击购买
- **THEN** 扣除价格、商品标记为已拥有并立即装备
- **AND** 顶栏余额同步更新

#### Scenario: 重复购买保护

- **WHEN** 玩家点击已拥有商品的购买入口
- **THEN** 不产生任何扣费

### Requirement: 头像与专属庆祝动作

商店 SHALL 提供 3 个可购买的占位头像 A / B / C 与默认头像。每个头像 MUST 绑定一个专属胜利庆祝动作，装备头像后，通关结算页 SHALL 播放该动作；默认头像沿用当前战斗角色的像素形象。

#### Scenario: 切换头像

- **WHEN** 玩家购买并装备头像 B
- **THEN** 商店与结算页显示头像 B
- **AND** 顶栏与结算页的头像同步变化

#### Scenario: 专属庆祝

- **WHEN** 玩家装备头像 A 并通关
- **THEN** 结算页播放头像 A 的专属庆祝动作
- **AND** 失败时不播放庆祝动作

#### Scenario: 庆祝动作目录

- **WHEN** 玩家查看商店的庆祝动作分类
- **THEN** 每个动作标注所属头像与解锁条件
- **AND** 未拥有对应头像时可直接前往购买

### Requirement: 攻击特效

商店 SHALL 提供可购买的答对攻击特效。装备后，答对攻击的那一次反馈 MUST 在敌人身上播放对应特效，默认特效保持现有命中表现。

#### Scenario: 闪电特效

- **WHEN** 玩家装备闪电冲击并答对
- **THEN** 敌人身上出现闪电特效并伴随命中抖动
- **AND** 特效在反馈结束后自动消失，不残留到下一题

#### Scenario: 默认特效

- **WHEN** 玩家未购买任何特效
- **THEN** 答对时只播放命中抖动，不出现粒子层

### Requirement: 胜利音乐

商店 SHALL 提供可解锁的胜利音乐。解锁并装备后，通关结算页 SHALL 播放 `assets/music/` 下登记的本地音频；未解锁、文件缺失、播放被拒绝或处于静音状态时 MUST 回退到合成胜利号角，且不得出现未捕获错误或白屏。音乐 MUST NOT 循环播放，并在离开结算页或静音时停止。

#### Scenario: 播放本地音乐

- **WHEN** 玩家已解锁胜利音乐并通关
- **THEN** 结算页播放登记的本地音频
- **AND** 不叠加合成号角

#### Scenario: 文件缺失回退

- **WHEN** 音乐文件不存在或浏览器拒绝播放
- **THEN** 自动改播 8-bit 胜利号角
- **AND** 控制台不出现未捕获错误

#### Scenario: 静音与离开

- **WHEN** 玩家在结算页开启静音或返回地图
- **THEN** 音乐立即停止

### Requirement: 清空进度

清空全部进度时，金币余额、已购商品与装备 MUST 一并清空并恢复默认，且需二次确认。

#### Scenario: 清空后状态

- **WHEN** 玩家在报告页确认清空进度
- **THEN** 金币归零、商品全部未购买、装备恢复默认
- **AND** 顶栏余额显示 0
