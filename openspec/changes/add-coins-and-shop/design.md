# Design

## 金币规则

- 单元关通关：金币 = 星级 × 难度倍数（轻松 ×1、标准 ×2、挑战 ×3），失败 0 枚。
- 重复通关继续给币：本游戏的目标是反复练习，不做防刷限制；商店价格按"十几次通关买齐"设定，避免一次通关就失去目标。
- 学期测验不发金币，保持"金币来自日常单元练习"的单一来源，减少规则解释成本。

## 经济数值

| 商品 | 价格（金币） |
| --- | --- |
| 头像 A | 18 |
| 头像 B | 24 |
| 头像 C | 30 |
| 胜利音乐「冒险胜利曲」 | 16 |
| 攻击特效「闪电冲击」 | 12 |
| 攻击特效「星星爆裂」 | 18 |

全部商品合计 118 枚。标准难度下 17 个单元全满星为 102 枚，接近买齐；挑战难度全满星为 153 枚，轻松难度为 51 枚。首次购买头像 A 需要标准难度 3 关满星，兑换节奏不至于太慢。

## 存档兼容

沿用存档键 `math-game.grade4.v1` 与 `version: 1`，新增字段在 `init` 时归一化补默认值：

```js
coins: 0,
owned: {},                 // 商品 id -> true
equipped: { avatar: 'default', music: 'default', effect: 'default' }
```

旧存档只有 `units / exams / wrongs / settings`，合并后星级、错题、设置全部保留；不提升 version，避免用户进度被判定为"损坏"而清空。

## 头像与庆祝动作

- 头像只做展示层，不改变战斗角色；默认头像直接显示当前角色（马里奥/林克）像素图。
- A / B / C 为字母色块占位，购买后可在商店切换。
- 每个头像绑定一个专属庆祝动作（欢呼跳 / 旋风转体 / 高举跳跃 / 星光摇摆），在通关结算页播放；庆祝动作随头像解锁，不单独收费，商店里单独列出以便预览和切换。

## 攻击特效

- 实现在敌人立绘上叠加纯 CSS 粒子层，答对的那一次反馈期间播放约 0.6 秒，随重新渲染自动消失。
- 默认特效不额外渲染，保持现有"命中抖动"。

## 胜利音乐

- 音乐文件通过 `data/music.js` 登记（默认指向 `assets/music/victory.wav`），未登记时完全不发请求，避免 404。
- 结算页优先播放已解锁的胜利音乐；未解锁、文件缺失、播放被浏览器拒绝或处于静音状态时，回退到既有 8-bit 胜利号角。
- 离开结算页、静音或重新开始关卡时立即停止音乐；音乐不循环、不做常驻 BGM。
