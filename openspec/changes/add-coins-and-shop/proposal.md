# Proposal

## Why

当前通关只留下星级，孩子打完之后没有可继续追求的目标；重复练习缺少正反馈，商店类收集又是这个年龄段最熟悉的激励方式。把"星级"直接折算成金币，再用金币兑换头像、胜利音乐、攻击特效和庆祝动作，可以让"多练一遍"变成"攒钱买喜欢的东西"，同时不引入任何付费或联网要素。

## What Changes

- 新增金币：单元关通关按「星级 × 难度倍数」结算（轻松 ×1、标准 ×2、挑战 ×3），失败不给；余额跨关卡累计并存档。
- 金币与 `add-difficulty-levels` 的难度设置联动：3 星在轻松/标准/挑战下分别为 3 / 6 / 9 枚。
- 新增金币商店 `#/shop`：顶栏显示余额并可一键进入；商品分头像、胜利音乐、攻击特效、庆祝动作四类。
- 新增 3 个占位头像 A / B / C（字母色块），每个头像带一个专属胜利庆祝动作；默认头像沿用当前战斗角色。
- 新增本地胜利音乐：购买后可替换 8-bit 胜利号角，播放 `assets/music/` 下的本地文件（内置一首示例曲，支持换成 mp3）。
- 新增攻击特效：购买后答对攻击时在敌人身上播放闪电或星星粒子，默认仍是普通打击。
- 扩展存档结构（金币、已购、已装备），旧存档自动补默认字段，不清空既有星级与错题。
- 清空进度时一并清空金币、已购商品与装备。

## Capabilities

### New Capabilities

- `coins`: 金币的获取规则、余额展示、持久化与旧存档兼容。
- `shop`: 商店目录、购买与装备流程、头像/庆祝动作/攻击特效/胜利音乐四类商品的行为。

### Modified Capabilities

（无：`game-shell` 的"无背景音乐"约束仍然成立，胜利音乐是由玩家主动解锁、仅在结算页播放的短曲，不构成常驻 BGM。）

## Impact

- 新增 `data/shop.js`（商品目录）、`data/music.js`（音乐登记表）、`js/music.js`（胜利音乐播放器）、`assets/music/`（示例曲与说明）。
- 修改 `js/store.js`（金币/已购/装备）、`js/ui.js`（顶栏、商店页、结算页、战斗特效）、`css/style.css`、`index.html`。
- 不引入第三方依赖、构建步骤或网络请求；音乐文件为本地静态资源，缺失时自动回退到合成音效。
